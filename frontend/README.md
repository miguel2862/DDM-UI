# Frontend DDM-UI

React, TypeScript y Vite para el motor R del DDM.

- `npm run dev`: desarrollo local.
- `npm run lint`: revisión estática.
- `npm run build`: compilación TypeScript y distribución.
- `VITE_API_TARGET`: URL de la API local (por ejemplo http://127.0.0.1:18000).

La vista de publicación y el inspector trabajan con las unidades, conexiones y resultados del DDM. Consulte [la guía](../docs/PUBLICATION_AND_STEP_BY_STEP.md).
